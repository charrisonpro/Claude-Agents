# Coach Conversation Log Template

Standard template for language coach session logging. Each coach maintains logs in their `History/` folder.

---

## File Naming

```
History/Log_YYYY-MM-DD_[student_name].md
```

Example: `Log_2025-01-19_Maria.md`

---

## Log Structure

```markdown
# Session Log: [Date]

## Context
- **Coach**: [Coach Name]
- **Student**: [Name or identifier]
- **Level**: [Beginner/Intermediate/Advanced]
- **Session Focus**: [Grammar/Vocabulary/Conversation/etc.]

## Summary
[1-3 sentence overview of what was covered]

## Topics Covered
- [Topic 1]
- [Topic 2]

## Student Progress
- **Strengths observed**: [What went well]
- **Areas for practice**: [What needs work]
- **Errors addressed**: [Corrections made]

## Dialect Features Introduced
- [Feature]: [Context/explanation given]

## Next Session Suggestions
- [ ] [Follow-up topic]
- [ ] [Practice recommendation]

## Notes
[Any additional observations about learning style, engagement, etc.]
```

---

## When to Log

Log at session end:
- After substantive learning interaction
- When significant progress or challenges observed
- Before extended break between sessions

---

## Linking to Student Status

After logging, update `Student_Status/[student_name].md` with:
- Current level (if changed)
- Topics covered (cumulative)
- Areas needing focus
