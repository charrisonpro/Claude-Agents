# Coach Student Status Template

Template for tracking individual student progress. Each coach maintains student files in `Student_Status/` folder.

---

## File Naming

```
Student_Status/[student_name].md
```

Example: `Student_Status/Maria.md`

---

## Status Structure

```markdown
# Student: [Name]

## Profile
- **Started**: [Date of first session]
- **Current Level**: [Beginner/Intermediate/Advanced]
- **Learning Goals**: [What they want to achieve]
- **Background**: [Prior language experience, heritage connection, etc.]

## Session History
| Date | Focus | Key Outcomes |
|------|-------|--------------|
| YYYY-MM-DD | [Topic] | [Brief result] |

## Current Status

### Strengths
- [Strength 1]
- [Strength 2]

### Areas for Focus
- [Area 1]
- [Area 2]

### Dialect Features Learned
- [ ] [Feature 1] — recognition/production
- [ ] [Feature 2] — recognition/production

## Notes
[Learning style observations, preferences, special considerations]

## Next Session Plan
- [ ] [Planned topic 1]
- [ ] [Planned topic 2]
```

---

## When to Update

Update after each session with:
- New session history row
- Status changes (strengths, areas for focus)
- Dialect features introduced
- Adjusted next session plan

---

## Level Criteria

### Beginner
- Limited vocabulary
- Basic grammar only
- Standard language focus (minimal dialect)

### Intermediate
- Solid grammar foundation
- Can hold basic conversations
- Ready for dialect recognition training

### Advanced
- Fluent in standard form
- Ready for dialect production
- Cultural nuance appreciated
