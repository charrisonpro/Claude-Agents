## Costa Rican Spanish Distinctive Features

### Voseo Conjugation Patterns

| Verb Type | Infinitive | Vos Form |
|-----------|------------|----------|
| -ar | hablar | vos hablás |
| -er | comer | vos comés |
| -ir | vivir | vos vivís |
| Irregular: ser | ser | vos sos |
| Irregular: tener | tener | vos tenés |
| Irregular: ir | ir | vos vas (no change) |

**Imperative (vos):**
- hablar → hablá
- comer → comé
- venir → vení

### Tico Expressions Quick Reference

| Expression | Literal | Contextual Use |
|------------|---------|----------------|
| Pura vida | Pure life | Greeting, farewell, "I'm good," "awesome" |
| Mae | — | Dude, buddy (casual) |
| Tuanis | — | Cool, great |
| Diay | — | Well, so, I mean (filler) |
| Upe | — | "Anyone home?" (calling into house) |
| Qué chiva | How goat-like | How cool! |
| Con mucho gusto | With much pleasure | You're welcome (replaces de nada) |

### Regional Variation

- **Central Valley (San José):** Standard reference for "tico" Spanish
- **Guanacaste:** More influence from Nicaragua, different vocabulary
- **Limón:** Caribbean influence, different rhythm and vocabulary
- **Rural areas:** May preserve more traditional forms

## Pedagogical Patterns

### Level-Appropriate Feature Introduction

| Level | Focus | CR Features |
|-------|-------|-------------|
| Beginner | Foundation | Usted, basic expressions (pura vida) |
| Elementary | Past tense, opinions | Introduce vos recognition |
| Intermediate | Complex structures | Vos production, diminutives |
| Advanced | Register, nuance | Full dialect, regional variation |

### Common Learner Errors

| Error | Correction | Note |
|-------|------------|------|
| Mixing tú/vos conjugations | Pick one form consistently | Tú works, vos is more natural |
| Overusing diminutives | Use for warmth/softening, not everything | Follow native patterns |
| False cognate: excitado | Use emocionado/entusiasmado | Important to correct |
| Overly formal usted | CR uses usted broadly but not coldly | Match context |
